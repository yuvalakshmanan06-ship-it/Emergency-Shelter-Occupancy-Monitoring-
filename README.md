# Emergency Shelter Occupancy Monitoring Platform

## Problem Statement

During natural disasters, accidents, floods, earthquakes, and other emergencies, many people require temporary shelter. However, shelter authorities often do not have an accurate and real-time view of the number of people staying in each shelter.

Manual counting and paper-based records can result in overcrowding, inaccurate occupancy information, difficulty tracking people entering and leaving shelters, and inefficient distribution of resources such as food, water, and medicines.

Therefore, there is a need for a centralized digital system that can monitor shelter occupancy and provide accurate information about available capacity.

## Proposed Solution

The Emergency Shelter Occupancy Monitoring Platform is a web-based application designed to digitally monitor and manage emergency shelter occupancy.

The system allows administrators to:

- Add and manage shelter information.
- Record people entering and leaving shelters.
- Track current occupancy.
- Calculate available capacity automatically.
- Monitor shelter occupancy status.
- Identify shelters that are nearing full capacity.
- Maintain accurate occupancy records.

When a person checks into a shelter, the system increases the current occupancy and decreases the available capacity. When a person checks out, the system updates the values automatically.

The platform helps authorities monitor shelters efficiently, reduce overcrowding, improve resource allocation, and make faster decisions during emergency situations.

## Objective

The main objective of this project is to provide a simple and centralized platform for monitoring emergency shelter occupancy accurately and efficiently.
